# Theme icons for the 4 new families — design

**Date:** 2026-05-22
**Scope:** Add dedicated tray + window icons for wabi-sabi, riso, constructivist, atomic. Extends the existing procedural recipe in `app/src-tauri/icons/generate-sk.ps1`.

## Motivation

The original 4 theme families (`holo`, `memphis`, `robotic`, `corporate`) each have a dedicated 256×256 PNG (`sk-<family>.png`) bundled into the Rust binary and swapped onto the tray + per-window icons by `set_tray_theme`. The 4 families added this week (`wabi-sabi`, `riso`, `constructivist`, `atomic`) don't — they silently fall through to `sk-holo.png` via the `_ => TRAY_HOLO_PNG` arm in `tray_icon_for`. Pick any of those themes and the tray icon stays Lisa Frank pink/cyan regardless of the active palette.

This change closes the gap.

## Approach

Match the existing pattern. Each icon is a 256×256 PNG generated by `generate-sk.ps1` with:

- A background (solid color, gradient, or solid + border)
- "SK" letters in a theme-appropriate font, centered, at 110–130px
- Either rounded corners (organic / mid-century / dreamy families) or hard-edge squares (industrial / terminal / poster families)

No new technology. Four additional `New-SkIcon` calls in the script, four new `include_bytes!` statements in Rust, four new match arms.

## Per-family parameters

| Family | Shape | Background | Text color | Font | Effect |
|---|---|---|---|---|---|
| **wabi-sabi** | Rounded (28%) | Solid `#c54a3a` (vermillion hanko-red) | `#f5efe0` (washi cream) | `Cormorant Garamond Italic` → `Yu Mincho` fallback | None |
| **riso** | Hard square + 2 px `#1f4587` border | Solid `#f5f0e5` (cream paper) | `#ff5589` (fluorescent pink) | `Bebas Neue` → `Impact` fallback | 4 px right / 3 px down `#1f4587` text-shadow (misregistration ghost) |
| **constructivist** | Hard square | Solid `#d91a28` (agitprop red) | `#efe6cf` (wheat cream) | `Alfa Slab One` → `Bahnschrift` → `Impact` fallback | Text rotated -4° |
| **atomic** | Rounded (18%) + 4 px `#2d2521` border | Solid `#f5ebd8` (butter cream) | `#c5552a` (brick orange) | `Limelight` → `Cooper Black` → `Georgia` fallback | None |

Approved visually in the brainstorm preview at 128 px and 24 px (tray size).

**Known compromise:** wabi-sabi and constructivist both read as dominant-red at 24×24 (vermillion vs agitprop). Acceptable — they're distinguishable up-close, and the OS tray rarely shows two snapper-keeper icons simultaneously.

## Implementation

### 1. PowerShell generator

Add four `New-SkIcon` calls to `app/src-tauri/icons/generate-sk.ps1`, following the existing format. The function already supports a gradient `BgFrom → BgTo`, hard-edge square or rounded, custom font + size + color. The riso misregistration ghost needs a small extension to draw the text twice: once in the ghost color offset, once in the primary color on top. Two options:

- (a) Add an optional `-GhostColor` and `-GhostOffset` parameter to `New-SkIcon`, hard-coded inside to draw the ghost first then the foreground. Single function, four new families fit.
- (b) Leave `New-SkIcon` alone, write a `New-SkRisoIcon` for the misregistration case.

Recommend (a). One function with optional parameter is cleaner than two near-duplicates.

The other three families fit the existing `New-SkIcon` signature without modification — solid bg, single text pass.

### 2. Rust side

In `app/src-tauri/src/main.rs`:

```rust
const TRAY_WABI_SABI_PNG: &[u8] = include_bytes!("../icons/sk-wabi-sabi.png");
const TRAY_RISO_PNG: &[u8] = include_bytes!("../icons/sk-riso.png");
const TRAY_CONSTRUCTIVIST_PNG: &[u8] = include_bytes!("../icons/sk-constructivist.png");
const TRAY_ATOMIC_PNG: &[u8] = include_bytes!("../icons/sk-atomic.png");
```

Extend `tray_icon_for`:

```rust
fn tray_icon_for(family: &str) -> Image<'static> {
    let bytes = match family {
        "memphis" => TRAY_MEMPHIS_PNG,
        "robotic" => TRAY_ROBOTIC_PNG,
        "corporate" => TRAY_CORPORATE_PNG,
        "wabi-sabi" => TRAY_WABI_SABI_PNG,
        "riso" => TRAY_RISO_PNG,
        "constructivist" => TRAY_CONSTRUCTIVIST_PNG,
        "atomic" => TRAY_ATOMIC_PNG,
        _ => TRAY_HOLO_PNG,
    };
    // ... unchanged below
}
```

### 3. Commit the generated PNGs

Run `pwsh app/src-tauri/icons/generate-sk.ps1`, commit the 4 new PNG files plus the script edit and the Rust changes as one commit.

## Out of scope

- Redesigning the existing 4 icons (the user explicitly picked "match existing pattern")
- ICO bundling for the Windows installer (the bundled `.exe` icon stays the generic `icon.ico` regardless of active theme — this PR is about runtime tray/window icons, not installer artifacts)
- Mac `.icns` variants per theme
- Smaller / larger sizes (256×256 is already what Tauri's tray runtime expects)
- A separate icon for the Settings card preview (the card already shows palette swatches + a divider preview; an icon would be visual noise)

## Testing

CSS-only changes in the PowerShell script don't have unit tests. Verification is by-eye:

1. Run `pwsh app/src-tauri/icons/generate-sk.ps1` and confirm 4 new PNG files appear with reasonable visuals
2. `cargo build` to confirm `include_bytes!` resolves correctly
3. Manual smoke: launch app, cycle through all 8 themes in Settings, confirm tray icon changes to match each family (4 existing should be unchanged, 4 new should show their dedicated icons)
4. Eyeball the tray icon at native size on a few DPI scaling settings — particularly the riso misregistration ghost (the offset may need adjustment if 4 px reads too aggressive at 24×24)
